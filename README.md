# Image Classification Model on Webcam

That's amateur project by me in which I am planning it for the purposes of learning more of computer vision.

Tested on: Arch Linux 6.18.7-arch1-1 XCB
For testing on other OS, it might require some changes on window management and paths.

`classes` folder include the photos that you are going to classify
`monkeys` will include the resulting images to be shown (in this context it is monkeys)
`process_images.py` will process these images to spesific resolution and etc to make good for the model.
`launch_camera.sh` will run the project. If you don't use Qt it is normal to give some errors
